# EPS Viewer for MadGraph

This tool automates the process of collecting, converting, and merging EPS files generated by MadGraph into a single, PDF viewer.

* MG5view = Madgraph with Atril (or Evince).
* MG5zat   = Madgraph with zathura.

## Overview
MadGraph often generates multiple EPS files scattered across temporary directories. This script:
1. Locates all .eps files generated in /tmp.
2. Filters out duplicates and empty/locked files.
3. Converts them to PDF format using Ghostscript.
4. Merges them into one all_diagrams.pdf file.
5. Displays the result using Zathura (with MG5zat) or Evince/Atril (with MG5view).

## Prerequisites & Installation
You need `ghostscript`, `poppler-utils`, and `zathura` (or Evince/Attril). Install them using:

With Zathura
```bash
sudo apt update
sudo apt install ghostscript poppler-utils zathura
```
with Evince
```bash
sudo apt update
sudo apt install ghostscript poppler-utils evince
```
with atril
```bash
sudo apt update
sudo apt install ghostscript poppler-utils atril
```

## Setup & Usage

### 1. Create and Configure the Script
Copy `MG5zat` in your MadGraph project root
or
Copy `MG5view` in your MadGraph project root

if you are using `Evince`, just edit `MG5view.sh` and replace:

```bash
xdg-open all_diagrams.pdf &
```
with
```bash
evince all_diagrams.pdf &
```

### 1. Madgraph Modification
Example with `MG5zat` (do the same with `MG5view`).

* Edit: madgraph/input/mg5_configuration.txt
* add: eps_viewer = [ABSOLUTE_PATH_TO_MG5zat]/MG5zat

### 2. Make it Executable
Run this command in your terminal:
```bash
chmod +x MG5zat
```
or
```bash
chmod +x MG5view
```

## Navigation Shortcuts (Zathura)
* j / k: Next / Previous diagram.
* Ctrl + j / Ctrl + k: Zoom in / Zoom out.
* r: Reload document.
* F11: Toggle fullscreen.
